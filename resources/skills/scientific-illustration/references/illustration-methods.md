# Make the scientific relationships visible

## Plan objects, actions and meaning

List the necessary objects, their relationships and the order in which the reader should see them. Distinguish a process arrow, a label leader, a physical connection and a proposed effect. Explain meaningful dashed lines or shading. Use an explicit legend when the meaning is not apparent from direct labels.

Base scientific structures on the supplied sources or reliable references. Do not invent a missing connection, component or mechanism to make the composition tidy. Mark a proposed relationship as a hypothesis. Disclose enlargement, omitted detail or schematic proportions when their interpretation could affect the reader's conclusion. A conceptual drawing does not justify a scale bar.

## Use editable vectors for structured diagrams

For a workflow, method or system diagram, define nodes and connections before styling them. Preserve the actual topology, direction and conditional branches. Arrange nodes with a clear reading order, consistent spacing and enough room for labels. Prefer direct or simple elbow connections; reduce crossings without deleting meaningful edges. Split a dense diagram when one canvas cannot explain it clearly.

SVG, drawing code and native presentation shapes can all provide editable source. Keep text as text where possible. Attach arrow endpoints to the intended objects, keep labels near their referents, and avoid leaders that cross other labels. Reopen the exported file to check that fonts, markers and connector placement survived conversion.

## Keep illustrative art separate from annotations

Use existing licensed art when it fits the task. Record its source and any reuse terms. For original illustrative art, choose vector drawing or an available image-generation capability according to the desired appearance. A remote generation request may send its prompt and reference images to that service, so use only content appropriate to the user's authorized task and destination.

When generating compositable art, describe the objects, perspective, essential relationships and label space. Request text-free art and add labels, arrows and symbols afterward in the editable layer. Request transparency when needed. Inspect the actual pixels for unwanted text, misleading structure and invented details. Generated art is an illustration, never experimental evidence or a validated structural model.

Do not use image generation for plotted measurements, instrument outputs or source imaging. Use actual data for quantitative marks. Keep the original artwork and preserve its aspect ratio. For placed raster art, check native effective resolution; enlarging or upsampling the file does not create scientific detail.

## Review meaning as well as appearance

Trace every connection and compare it with the intended explanation. Check that labels refer to the correct objects and that color does not imply an unsupported category or result. Inspect the final-size composition for clipping, line collisions, small text and missing symbols. Replacing an image can move its features, so check annotation anchors again after a revision.

Deliver an editable composition when feasible, plus the requested viewing format. Keep source credits and any appropriate generated-art disclosure with the deliverable. For publication, check the destination's current illustration and AI-art policies rather than assuming acceptance. Report what has and has not received specialist review.
