# Scientific data visualization

Start with the scientific question, the comparison the reader must make, and the available evidence. Identify the observation unit, variables, units, transformations and uncertainty before choosing a chart. Use the user's existing analysis when supplied; changing the analysis is a separate decision from improving its display.

Use [the style guide](references/style-guide.md) for appearance. Read [figure methods](references/figure-methods.md) when planning panels, handling uncertainty, reproducing source material or exporting a final figure. Choose the parts relevant to the requested output rather than requiring a fixed contract or gate suite.

Build quantitative marks from data or explicitly cited values with reproducible code. Preserve the original inputs and document consequential filtering or transformations. Never generate evidence images, traces or data points to make a figure look complete. Clearly label synthetic demonstrations, model predictions and estimates read from a plot.

Give each panel a distinct job and make the reading order clear. Define measurements, axes, sample sizes and error bars where the reader needs them. Keep the source's claim strength and unresolved conflicts visible.

Before delivery, compare the plotted values with their inputs and inspect the actual export at its intended size. Check labels, clipping, color meaning, uncertainty and whether the figure supports its stated message. Deliver an editable source or plotting code with the requested figure when feasible, and state any verification that could not be performed.
