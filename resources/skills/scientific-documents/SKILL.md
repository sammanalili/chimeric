# Scientific documents

Use the requested audience, purpose, format, length and language. Carry forward existing preferences and ask only for missing information that blocks useful work. Read the supplied scientific material before designing the document; a polished layout must not conceal an unsupported claim.

Build a clear path from context and question through approach, evidence, interpretation and limitations. Adapt that path to the assignment rather than imposing a fixed page or slide count. Give the reader enough explanation to understand a result and its practical limits. Keep quantities, sample scope, source credits and uncertainty intact.

Use [the style guide](references/style-guide.md) for appearance and voice. Read the relevant part of [reports and presentations](references/reports-and-presentations.md) for file structure, notes, language placement and review. The workflow is self-contained and can use the authoring tools available in the current environment.

Prefer editable text, charts, shapes and tables when the requested format supports them. Use source figures faithfully and original explanatory graphics where useful. Create additional formats or review records only when requested or when they solve a concrete delivery need.

Inspect the actual exported pages or slides. Check scientific claims and numbers against their sources separately from layout checks. Deliver the requested file, retain useful editable source when feasible, and state any remaining source, rendering or language-review limits without claiming checks that were not performed.
