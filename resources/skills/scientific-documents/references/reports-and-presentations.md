# Build the file around the reader's task

## Reports and handouts

Start with the main question and the finding or decision the reader needs. Explain enough background to make the evidence understandable. Keep methods proportional to their role in interpreting the result. Put detailed calculations or supporting material in an appendix when the main argument remains complete without them.

Use connected paragraphs for reasoning and tables for parallel comparisons. Define quantities, abbreviations and sample units near their first use. Place captions and source credits close to the relevant figure. A source conflict or missing value should remain visible and should narrow the conclusion when necessary. Cite the exact work supporting the claim; do not use citation count or an institution's reputation as a substitute for evaluating the evidence.

Follow the requested document format and page size. For paged output, reserve space for headers, footers and captions, and keep headings with the following content. Use real tables and styles in an editable format when available. For HTML-based output, use explicit print styles, sensible page breaks and a declared language. Repair overflow through content or layout changes rather than hiding it.

## Research presentations

Build a talk that a colleague can follow without having read the paper. A useful sequence is context, question, approach, key results, interpretation, strengths, limitations and the next discussion or decision. Adapt this to the requested time and audience. Do not impose a fixed slide count, title formula, note length or visual count.

Use the actual key figures when explaining a paper, with a short source credit and figure identifier. Tell the audience what to examine and what the result means. State whether a count represents independent samples, repeated measurements or another unit. Show important caveats on the relevant result slide rather than relying entirely on notes.

Use speaker notes for the explanation the presenter needs: context, figure walkthroughs, methods, qualifications and references. Notes can vary in length. Keep the essential claim and evidence understandable from the slide itself. Use actual questions that support discussion when a discussion section is appropriate.

## Bilingual documents and notes

Follow the requested language order and register. A presentation may use one language on the slide and the other in notes. Use stacked or side-by-side text only when both are needed by the reader. Preserve names, citations, signs, quantities, units, denominators and claim strength in translation. Use established Japanese terms and natural sentence structure instead of translating English word order.

Use fonts with the required glyph coverage and inspect Japanese line breaks in the real export. Keep closing punctuation with the preceding phrase and opening punctuation with the following text. Reflow text before making it too small. Check data marks and non-text meaning for consistency across language versions. Do not describe an agent translation as native-speaker review.

## Source figures and original graphics

Preserve the scientific content, proportions, scale information and meaning of source figures. Explain them beside the image instead of redrawing evidence to make it cleaner. Keep an exact source credit and observe applicable reuse terms. Build new charts from data and use editable diagrams for concepts. Clearly label illustrative or generated artwork so it cannot be mistaken for observations.

## Review the delivered file

Open or render the actual final file and inspect each page or slide for readability, clipped content, awkward breaks, missing glyphs, incorrect cropping and excessive density. Check tables, figure captions, slide order, speaker notes and links that matter to use. Verify that the requested file is present and opens in the intended format when the environment permits it.

Separately compare reported numbers, scientific claims and source credits with the supplied material. A file-format validator cannot establish scientific accuracy. If export or visual inspection is unavailable, identify that limit instead of treating a successful authoring step as a completed review. Recheck current official requirements only when a named publication or other destination requires them.
