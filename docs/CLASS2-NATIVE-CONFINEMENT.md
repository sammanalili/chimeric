# Class 2 must gate native processes and host calls before dispatch

This is an implementation map, not a confinement attestation. Inspection on 2026-11-20 used the checked Darwin 0.1.71 original core at `work/runtime-recovery/original/claude-science`, SHA-256 `e3674e221f9079520f014eb2ef93d0ba151934a47fd561594efcb23a86809e0b`. No live profile, user research, credentials, network inference, or installed application was changed for this audit.

`SessionPolicyStore.assertLane` already denies an unverified Class 2 lane. The remaining work is to call it from every actual native dispatch boundary with a trusted current frame context. A hidden tool, model instruction, standing domain decision, or JavaScript HTTP wrapper does not enforce that boundary.

## Existing native hooks cover distinct execution paths

Line numbers below refer to the original core, before build-time edits. Use checked AST anchors and exactly one match for each patch. The Linux build has a different revision and must be checked independently.

`FEo` also exposes dynamic/default host operations. A Class 2 allowlist must be applied before that default branch, not just to the named `mcp` case. Browser app/iframe handlers and resources need their own boundary. Unsupported dynamic routes must remain blocked instead of inheriting general execution permission.

## Existing sandbox profiles provide a possible offline lane

The native `X0e()` helper at line 30032 returns a disabled network configuration with no proxy ports, no local binding and no Unix sockets. `_deriveSubprocessWrap`, line 30734, uses that configuration when `denyNetwork` is true. On Linux, `wrapSubprocessArgs` also supplies `socketPaths:null`.

On macOS, `J4e`, line 30591, executes `sandbox-exec -p <generated profile> -- <argv>`. `zjn`, line 30027, starts the generated profile with `deny default`. `z$l`, line 29996, adds no network permissions when network is disabled. This is a plausible OS enforcement path. It is not yet evidence that every native child, resolver, IPC channel or sensitive file is confined.

The sandbox manager has shared analysis, operon, BYOC and inference proxies. `_rebuildAllowlist`, line 30734, combines baseline and saved extra domains and updates those shared proxies. Do not mutate that global allowlist to implement one chat’s confidentiality. Other ordinary sessions may still be running. Protected processes must have no route to those proxies, and their host-call routes must be gated separately.

File access is also profile-specific. `KA`, line 30575, derives analysis frame paths, Conda roots, user grants, artifact roots and helper paths. `_deriveSubprocessWrap` can reallow a frame secrets directory. Protected execution must not receive provider keys, credential-bearing frame secrets or unrestricted credential requests. A network deny alone does not protect credentials from entering an approved model’s next context.

## Explicit outbound actions use the existing broker

Expose a structured preparation action to the selected protected model. It supplies the purpose, transformed copy, exact connection, method, URL, query, headers, body and uploads. Loading a local skill can help prepare this action; it cannot authorize its later network traffic.

The authenticated user reviews `OutboundBroker.prepare(context, intent)` and approves its current digest. `send` consumes that specific branded permit through the injected credential-owning transport. Do not call a network-capable skill, MCP server or shell command after approving an HTTP draft: that would authorize a different operation. Initially, execute only the reviewed HTTP operation and return its bounded response to the protected model.

The transport must attach credentials after review, check the exact connection revision and API path prefix, use the supplied cancellation signal, reject redirects and avoid replay/retries. The native process receives no broker credential or reusable domain permission. URL query strings, actual payload and uploads stay visible in the review. IP and approximate location must be described as observable or unknown, not guessed.

## A bounded staged Mac test can establish the first local lane

Run this only on a disposable copy of the staged runtime and a fresh fixture profile, with synthetic data and a clean child environment. Never attach to the installed research daemon. Pin all model and background roles to a loopback fixture. Intercept or deny all other daemon HTTP before startup, so a missing stub cannot become a real request.

1. Record hashes of the staged native core, backend, sandbox wrapper and generated policy, plus OS architecture/version. Patch only the test copy to expose or record the actual native wrapper output. Keep source checks proving the copied method and wrapper are unchanged. A hand-written substitute SBPL profile is not this test.
2. Create a private fixture root with a writable project directory, a separate local-auth canary, sibling project canary and an outside-home canary. Use synthetic bytes. Set restrictive permissions. Do not read real authentication files or home-directory contents.
3. Start parent-owned IPv4/IPv6 loopback TCP listeners, an HTTP proxy canary and a Unix socket outside the child’s allowed paths. Record accepts and received bytes. Demonstrate the unconfined control can reach them and read all synthetic files. Keep test payloads bounded to small fixed strings and use 1–2 second socket timeouts.
4. Through the actual native Python process lane, run arithmetic, write/reopen an artifact in the granted project and launch a child process that repeats the checks. Attempt TCP/HTTP/WebSocket-style socket handshakes, UDP to a local canary, a connection to the shared proxy and the Unix socket. Require an OS permission denial and zero accepts/bytes. Connection refused, timeout and an unreachable host are inconclusive, not a pass. Do not contact an external DNS resolver; inspect the actual Mach/socket policy and test a controlled local resolver path separately before claiming DNS coverage.
5. Attempt the synthetic secret and sibling reads and writes, direct and via a symlink. Require permission denials while the intended project remains usable. Check the child environment lacks synthetic provider/credential markers. Verify forked children inherit the same restrictions and cannot reach parent loopback or the broker socket.
6. Seed a standing domain grant, a permissive local-execution grant and a warm ordinary kernel in the fixture. Enable Class 2. Prove the old kernel/process is stopped before protected work starts, saved domain permission does not grant egress, and a missing sandbox fails before spawn. Test queued and in-flight cancellation on mode, connection and owner/root changes.
7. Exercise both ordinary top-level tools and kernel host calls. Require denied MCP, app handlers, remote compute, provisioning and unmanaged shell to perform zero delegated invocations. Exercise direct notebook/user-code routes as well as model-selected tools. Keep normal sessions on the same fixture working, to detect accidental global policy mutation.
8. Run one brokered HTTP request to a parent-owned loopback capture endpoint containing only synthetic transformed bytes. Assert zero traffic before approval; after Send once, compare the captured method, URL/query, relevant headers and body bytes with the reviewed digest. Test duplicate sends, edits, redirects and cancellation. Confirm no chat history, hidden context, filenames or originals were appended.

Time-bound each child and the whole fixture, terminate its process group on timeout, close listeners and remove only that fixture root. Retain a small receipt containing hashes, pass/deny/inconclusive results, permission-error categories and traffic counts. Do not save research contents or credential values.

Only the tested exact build and lane can be marked verified. Linux, WSL, Docker, native R, converters, ASR, remote compute and browser content remain unverified until separately tested. Existing E2E tests that manually construct an SBPL deny rule establish that the OS can enforce that rule; they do not establish that the app actually selected it.
